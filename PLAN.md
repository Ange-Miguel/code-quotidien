# Plan des 200 jours

Un problème par jour, du plus simple au plus avancé. Les langues alternent : C → Python → Java.
Chaque jour a son dossier `jour-XXX/` avec le code et un `README.md` qui explique le problème et la solution.

Statut : `[x]` fait, `[ ]` à venir.
